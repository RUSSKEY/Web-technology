# Web-technology

Лабораторные работы по предмету «Основы веб-технологий».

## О проекте

Сайт «КАФЕ у Дома» — небольшой сайт кафе с домашней кухней.  
Сделан в рамках изучения HTML, CSS, JavaScript и работы с формами.

## Что внутри

- **LR1** — вёрстка главной страницы (HTML, CSS)
- **LR2** — страница «Собрать ланч» с меню на Grid и Flexbox, адаптивность
- **LR3** — форма заказа с отправкой на httpbin.org
- **LR4** — динамический вывод блюд через JS, добавление в корзину, подсчёт стоимости, сортировка
- **LR5** — фильтры блюд по категориям, 2 новые категории (салаты, десерты), расширение меню до 30 блюд
- **LR6** — блок с комбо-ланчами и анимация иконок, валидация формы при отправке, всплывающие модальные окна с ошибками
- **LR7** — загрузка данных меню с сервера через API (fetch), обработка ошибок
- **LR8** — страница оформления заказа, сохранение выбора в LocalStorage, отправка заказа на сервер (POST)
- **LR9** — страница истории заказов, получение списка заказов с сервера, модальные окна для просмотра, редактирования (PUT) и удаления (DELETE) заказов.

## Страницы сайта

- `index.html` — главная (о нас, преимущества, топ блюд)
- `menu.html` — меню из 5 категорий, блок с комбо-ланчами, прилипающая панель
- `checkout.html` — страница оформления заказа (состав заказа и форма)
- `orders.html` — история заказов пользователя (таблица с действиями)

## Категории меню

- Супы (6 блюд)
- Главные блюда (6 блюд)
- Салаты и стартеры (6 блюд)
- Напитки (6 блюд)
- Десерты (6 блюд)

## Скрипты

- `script.js` — загрузка данных с сервера, рендер карточек, фильтрация, корзина (LocalStorage)
- `checkout.js` — логика страницы оформления, удаление блюд, отправка заказа (POST)
- `orders.js` — логика истории заказов, расчёт стоимости, модальные окна (просмотр, PUT-редактирование, DELETE-удаление)
- `upload.js` — утилита для загрузки локальных блюд на сервер (использована 1 раз для ЛР7)

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, медиа-запросы, анимации transform, position: fixed/sticky)
- JavaScript (DOM, массивы, объекты, fetch, async/await, LocalStorage, события, preventDefault)
- REST API (методы GET, POST, PUT, DELETE)
- Google Fonts (Roboto)
- Git, GitHub Pages
